# Калибровка и балансировка жёсткого двухопорного ротора

[![Deploy](https://github.com/tru17v/balance/actions/workflows/pages.yml/badge.svg)](https://github.com/tru17v/balance/actions/workflows/pages.yml)

Расчёт динамических жёсткостей опор (калибровка пробными грузами) и корректирующих масс
(балансировка в двух плоскостях) для жёсткого ротора на двух опорах.

**Веб-версия:** https://tru17v.github.io/balance/

## Веб-версия

Статический сайт в папке [`web/`](web), без сборки и сервера — расчёт выполняется в браузере.

| Файл | Назначение |
|------|------------|
| [`web/core.js`](web/core.js) | ядро расчёта: геометрия схем, калибровка, балансировка, разложение по позициям, допуск по ГОСТ 22061-76 |
| [`web/app.js`](web/app.js) | интерфейс: пуски, схема ротора, полярные диаграммы, допуск, 3D-графики |
| [`web/index.html`](web/index.html), [`web/style.css`](web/style.css) | разметка и оформление |
| [`tests/core.test.js`](tests/core.test.js) | проверка ядра на синтетических данных |

- **Запуск локально:** открыть `web/index.html` в браузере. Интернет нужен только для 3D-графиков (Plotly подгружается с CDN; без сети остальная страница работает).
- **Тесты:** `node tests/core.test.js` (на macOS без Node: `jsc web/core.js tests/core.test.js`).
- **Публикация:** workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) прогоняет тесты и при пуше в `main` выкладывает `web/` на GitHub Pages.

### Порядок работы

1. **Ротор и режим** — схема расположения плоскостей коррекции, длины участков, рабочая частота вращения.
   Для каждой схемы геометрия запоминается отдельно; схема ротора рисуется в масштабе.
2. **Калибровка**
   - *Пуск 0* — вибрации опор без пробных грузов (можно отключить для заранее уравновешенного ротора).
   - *Пробные грузы* — устанавливаются в обе плоскости одновременно.
   - *Пуск 1* — вибрации опор с пробными грузами.
3. **Балансировка** — по умолчанию используются вибрации пуска 0. Для доводочного пуска снимите связь
   и введите вибрации после установки грузов — получите добавочные грузы.
   Если груз можно ставить только в отверстия или пазы, укажите их число: груз будет разложен по двум соседним позициям.
4. **Допуск по ГОСТ 22061-76** — масса ротора, класс точности, эксплуатационная частота и положение центра масс;
   дисбаланс в каждой плоскости сравнивается с допустимым.

Вибрацию можно вводить в любых единицах (мкм, мм/с), если они одинаковы во всех пусках: на массы и углы грузов это не влияет.
Углы грузов отсчитываются от той же метки и в том же направлении, что и фаза прибора.

### Модель

Ротор жёсткий, опоры A и B независимы: вибрация опоры x = D / k, где D — динамическая нагрузка на опору,
k — комплексная динамическая жёсткость (Н/мкм). Нагрузки на опоры от сил в плоскостях 1 и 2 находятся
из равновесия моментов. Калибровка: k = D / (x₁ − x₀). Балансировка решает обратную задачу и находит
дисбаланс U в каждой плоскости; **корректирующий груз той же массы ставится под углом φ<sub>U</sub> + 180°**
(или снимается материал под углом φ<sub>U</sub>).

Динамическая жёсткость зависит от частоты, поэтому калибровка и балансировка выполняются на одной частоте n.

Допуск: e<sub>ст</sub> = (e·ω)<sub>класс</sub> / ω<sub>max</sub>, D<sub>ст</sub> = m<sub>рот</sub>·e<sub>ст</sub> (формула (4) без технологических
и эксплуатационных составляющих), D₁ = D<sub>ст</sub>·|l₂ − L<sub>ц</sub>| / |l₂ − l₁|, D₂ = D<sub>ст</sub>·|L<sub>ц</sub> − l₁| / |l₂ − l₁| (формулы (7), (8)).

### Схемы расположения плоскостей

Координаты отсчитываются от опоры A; a = l<sub>A1</sub>, b = l<sub>12</sub>, c = l<sub>2B</sub> — положительные длины.
Формулы ПК и МОПК (а также ЛК и ЛКМО) совпадают — схемы различаются порядком точек, который зависит от длин.

| Схема | Порядок точек | z₁ | z₂ | z<sub>B</sub> | Пример a / b / c, мм |
|-------|---------------|----|----|-----|-----|
| МО — межопорная | A · 1 · 2 · B | a | a + b | a + b + c | 75 / 195 / 265 |
| ПК — правая консоль | A · B · 1 · 2 | a | a + b | a + b − c | 520 / 120 / 240 |
| МОПК — межопорная + правая консоль | A · 1 · B · 2 | a | a + b | a + b − c | 100 / 450 / 120 |
| ЛК — левая консоль | 1 · 2 · A · B | −a | b − a | b − a + c | 240 / 120 / 520 |
| ЛКМО — левая консоль + межопорная | 1 · A · 2 · B | −a | b − a | b − a + c | 100 / 450 / 120 |
| ДК — двухконсольная | 1 · A · B · 2 | −a | b − a | b − a − c | 100 / 600 / 100 |

Если при введённых длинах порядок точек не совпадает со схемой, интерфейс предупреждает об этом и не выносит вердикт по допуску.
